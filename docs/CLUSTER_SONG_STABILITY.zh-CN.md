# 原车歌曲信息补充

我在 2023 唐 DM-i 冠军版、21 控制器上遇到原车歌曲栏写入不稳定，以及歌名和歌手挤在一起的问题。本次在主线已有歌曲、播放状态、切歌显示 5 秒及滚轮提示功能上补充适配。 自用版已在 2023 唐 DM-i 冠军版、平台 21 验证；公共移植分支尚待实测报告。

来源字段从车机 SDK 的 `INSTRUMENT_MUSIC_SOURCE_SET` 解析，只接受已核对的 `0x43E00030` / `0x38F00030`，设备仍为 1007。字段缺失或未知时不猜写来源地址，播放状态和文字仍分别尝试。每个字段独立确认，来源失败 30 秒后再试，状态失败 5 秒后再试，避免每句歌词重复写控制字段。保留主线已观察到的厂商返回值兼容；文字成功不代表来源成功，日志单独给出来源确认情况。

ADB 使用已授权的专属交互 shell，常驻 app_process 初始化一次 SDK，不新增网络服务。关闭歌曲总开关或 CarPlay 会话结束时，写入队列发送 stop，尝试清空歌曲卡后关闭 shell/ADB 连接，worker 返回后退出。仅关闭 DiPlay 页面不会结束仍运行的会话。DiPlay 进程被结束或 ADB 断开时，worker 读到 EOF/错误便退出；若连接未及时反映断开，客户端不再每 5 秒续租，worker 在超过 15 秒后由下一次每秒巡检退出。厂商写入阻塞时也由该看门狗退出；退出和清卡的实际车机表现仍待公共分支实测。

令牌由客户端在每次启动 worker 时使用 SecureRandom 生成 16 字节随机数，转为 32 位十六进制，经已授权 ADB shell 的 app_process 启动参数传入；每条标准输入请求带同一令牌。令牌仅保存在客户端和 worker 内存中，不写入设置、文件或应用日志；它也出现在启动命令参数中，并不是对同权限 shell 隐藏的凭据。协议只接受受限的歌曲字段写入，不提供任意 shell 执行。

新增“原车歌曲栏显示歌手”，默认开启，立即生效，仅改变原车歌曲栏，Android 媒体元数据保持完整。原有歌曲总开关默认关闭，不改变公开包名及品牌。测试覆盖 SDK 字段、失败隔离、控制字段退避和协议约束，保留大字体、多语言及 RTL 自动排版检查，合成图只在 PR 描述展示，不随源码提交。没有安装到车机，worker 在不同 ROM 的权限、续租表现及实际仪表显示需要实车验证。
